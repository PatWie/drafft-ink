# drafftink-cli

Headless command line library for Drafft.ink: run command scripts, convert documents, print outlines and list commands.

**This crate has no binary.** The program is `drafftink-headless` (`cargo install drafftink-headless`): `drafftink-headless convert in.mmd out.drafftink`, `run`, `outline`, `inspect`, `commands`, `schemas`.

Part of [Drafft.ink](https://drafft.ink), an infinite canvas whiteboard written in Rust. See the [main README](https://github.com/PatWie/drafft-ink#readme) and the [documentation](https://github.com/PatWie/drafft-ink/tree/main/docs) for the whole project and how the crates fit together.
