## 3. Ranked violations and gaps

Severity: **High** = can lose or corrupt user data, or breaks a stated guarantee in normal use. **Med** = a spec clause is weakened or a promised check is absent. **Low** = polish, docs, hardening.

### High

1. **Remote merges are not repaired (A9, A7).** `engine/src/remote.rs:83 after_remote` and `invariants.rs:23` skip the relation pass for remote updates. Probes: two peers move different targets of one arrow, so the arrow ends detached on both; delete races `arrow.bind`, so a binding points at a deleted element; concurrent group/ungroup is untested. `doc/tests/converge.rs:433` never generates these ops. Fix: after `apply_remote`, run `validate_scene` plus a deterministic repair (drop dangling bindings, dissolve groups under 2 live members, re-solve bound arrows) without an undo step, extend the generator with `group_ids`, bindings, `frame_id`, points and undo, and assert `validate_scene` after every sync. Correct or implement the gesture-abort claim in `docs/protocol.md:210`.
2. **A batch that changes tab loses atomicity (D1/E).** `batch.rs:~440-442,542` marks and rolls back only the start tab, while `tab.new` and `tab.switch` are `Batch::Allowed` (`cmd/tab.rs:553`). Probe: `[element.create, tab.new, element.create]` leaves the second element in the new tab with `undo_depth=0` and no CRDT write; `[tab.new, element.create, <bad>]` reports `rolled_back=true` but keeps the element. Fix: make `tab.new/tab.switch` `Batch::Last`, or track mark per tab; add both cases as tests.
3. **`window.drafftink` and WebMCP calls hang while the tab is hidden (D9).** `gpu/src/repaint.rs:57` suppresses redraws when hidden and the bridge queue drains only inside a frame (`app.rs:~1016`). Fix: drain the queue from a timer or `MessageChannel` task without drawing, or reject with "tab is hidden" after a timeout; add an e2e with a second tab.

### Medium

4. **The exceptions gate does not exist (D10).** `docs/exceptions.md` rule 8 and the comments at `interact/select_tests.rs:5` cite `cargo xtask exceptions --check`; the gate is unknown, and E13/E14/E15 lack their named tests while E13/E14 describe features that are not built. Fix: add the gate (a registry test that reads `docs/exceptions.md` is enough: every `Undo::Gesture` command has a row, every row names a registered command, every row has an `exception_<id>_*` test), add the three tests, trim E13/E14 to what exists, and list `install_scene` and `on_write_done`.
5. **State-change fences can be bypassed (D2).** Make the `Session` fields `pub(crate)` with read accessors and give the UI a read-only view type, so a UI write fails to compile; guard `crates/app` like `thin.rs` or move `install_scene` behind an engine method gated by `cfg(feature = "scenarios")` and drop that feature from the shipped native binary (`apps/drafftink/Cargo.toml:14`).
6. **Facts are partly name lists, and omission is catchable only for some fields (D8).** Add registry fields `replaces_document`, `repeat_ok`, `quiet_from_keyboard`, `agent_tool`, `closes_dialog` and delete `DOC_EXEMPT_*`, `HAS_OWN_TOOL`, the `"text.edit_end"` special cases and the UI `match call.id` arms; make the family bases non-permissive (a command must state `view_only` and `agent`); add a base-ref shrink check for `unregistered.txt` or delete the file.
7. **Domain rules duplicated in commands and UI (D7).** Move `snap_move/snap_resize` into `edit`, one `ExportLimits` in `io`, one zoom clamp in `canvas`, sequence-diagram layout geometry into `edit::layout`, image sniffing into `io::picture`, layout validation into `LayoutError`; read UI limits (name lengths, export scale default) from the engine; tie `settings/keys.rs` word lists to the enums with `ALL` consts or a round-trip test.
8. **UI refusal presentation (D5).** Replace UI-authored reasons (`tabs.rs:118-122`, `topbar.rs:23`, `export.rs:88,92`, `collab.rs:195`) with the engine's availability text; disable instead of hide in `context_menu.rs` and `props.rs`; show `gesture.end` refusals (suppress only the "no gesture" code); make `commands()` report `not_for_agents`; add one test that the toast, availability and bridge texts for a refused command are identical; rewrite the 8 sampled refusals without a next step and map user-reachable domain errors away from `internal`.
9. **Layering enforcement is a denylist (D3).** Invert `EXTERNAL_RULES` to a per-layer allowlist taken from `cargo metadata`, run the engine source scan over every crate below L6, add `disallowed-types` for `egui::*`, `rfd::*`, `web_sys::Window` to `clippy.toml`, treat non-member path deps as external, and correct the transitive-dependency wording in `engine/tests/layering.rs`.
10. **Shipped server lacks sqlite and s3; S3 test is vacuous by default (A12).** Build the packaged server with `--features sqlite,s3` and smoke-test `--storage sqlite` on the packaged binary, or make them default; make `s3_real_endpoint_when_configured` `#[ignore]` with a reason or fail without the env var, and add a MinIO job.
11. **`doc.export` reports success when the write was refused (D4).** `engine/src/ports.rs:475` turns the failure into a warning; make a failed write with a path a refusal, as `doc.save` does.
12. **Fixture facts are partly typed by hand and the gate silently skips (T5).** `xtask/src/gates.rs:99-110`: resolve the old app from `DRAFFTINK_OLD_APP`, fail under `CI`, parse `--check`; add `fixtures` and `harness` jobs to `ci.yml`; make scenarios and the Rust tests listed in T5 read `*.facts.json`; add the sketch oracle to `regen.sh`.
